# Нууц цэцэрлэг

QR-аар нээгддэг, нууц үгтэй 3D цэцгийн жижиг сайт.

## Гол зүйлс

- Нууц үг: `0217`
- Тусламж: `чиний төрсөн өдөр`
- Цэцэг: сарнай, алтанзул, сараана
- 3D эргүүлж харах боломжтой
- Монгол хэл дээрх дэлгэрэнгүй танин мэдэхүйн тайлбартай
- Дотроо тухайн сайтын URL-аар QR үүсгэнэ

## GitHub Pages дээр асаах

1. Энэ хавтасны файлуудыг GitHub repo руу push хийнэ.
2. Repo дээрээ `Settings` → `Pages` орно.
3. `Build and deployment` хэсгээс `Deploy from a branch` сонгоно.
4. Branch: `main`, Folder: `/root` гэж тохируулаад `Save` дарна.
5. Гарсан GitHub Pages URL руу ороход QR нь автоматаар тэр URL-аар шинэчлэгдэнэ.

## Local шалгах

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Дараа нь `http://127.0.0.1:8080` хаягаар нээнэ.
